# Literature Review


## Social Robotics
Social robots use verbal and nonverbal behaviors to communicate with humans.

## Facial Expression Representation
The Facial Action Coding System (FACS) represents facial expressions using action units.

## Robot Expression Generation
Platforms such as PyLips allow researchers to create expressive robot faces.

## Language Models
Recent work shows LLMs can reason about social context and generate robot behaviors.

## Research Gap
Current systems often require manually designed mappings between language and robot expressions.
